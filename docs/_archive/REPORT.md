## 四、性能分析与优化建议

### 4.1 精度分析

当前 mAP@0.5 = **49.4%**，处于中等偏下水平，主要原因：

1. **类别不平衡**：部分类别（如灰飞虱）训练样本稀少，导致 AP 极低
2. **形态相似性**：飞虱类（褐飞虱 / 白背飞虱 / 灰飞虱）形态接近，易混淆
3. **模型规模**：使用的是 YOLO v11n（nano 级），参数仅 2.6M，轻量但精度有限

### 4.2 潜在优化方向

| 方向 | 方法 |
|------|------|
| 提升精度 | 改用 YOLO v11s / v11m 等更大模型 |
| 数据增强 | 对少样本类别做 Mosaic / MixUp / 水平翻转增强 |
| 部署提速 | 导出 ONNX FP16，使用 CoreML（iOS）或 TFLite（Android）部署 |
| 移动端优化 | 输入分辨率降至 416×416 或 320×320，进一步降低延迟 |
