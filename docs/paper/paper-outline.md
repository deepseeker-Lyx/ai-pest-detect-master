> **中文标题**：基于知识蒸馏与开放集识别的轻量化感知-认知协同水稻害虫诊断系统

## 摘要（Abstract，~250 词）

**结构模板**：背景痛点 → 方法框架 → 关键结果 → 应用价值

> 水稻害虫造成重大产量损失，但基层农户缺乏专业识别工具，且**计算资源受限**（CPU 部署）。本文提出一个面向低资源农业场景的**轻量化感知-认知协同**水稻害虫诊断系统。①在**感知层**，通过知识蒸馏将 20M 参数的教师模型压缩至 2.6M 的学生模型，并设计**条件触发的伪装色增强**提升田间弱对比度鲁棒性；②引入**多级开放集识别**，对未知虫种拒绝分类而非强行归类；③在**认知层**，构建 FAISS 语义知识库与大模型联动的问答系统，实现从"识别"到"决策"的闭环。在 DST1794 数据集（16 类、9772 张）上，蒸馏模型将 mAP@0.5 从 49.4% 提升至 74.6%，推理速度与模型体积不变；消融实验验证了各模块的独立贡献；系统已在阿里云 CPU 服务器部署运行，单张推理约 800ms。结果表明：在硬件受限的农业场景中，**知识压缩比单纯扩大模型更具工程价值**。

## 第三章 方法（Method，~4 页，论文核心）

### 3.1 系统总体架构（对应架构图）
```
感知层（预处理+检测） → 决策层（拒识） → 认知层（知识+LLM）
```

### 3.2 知识蒸馏轻量化检测
- 教师 v11m（20M）→ 学生 v11n（2.6M）
- 损失定义（⭐ 必须有公式）：
$$L_{total} = \alpha L_{detect} + \beta L_{distill}$$
$$L_{distill} = \frac{1}{N}\sum_{i=1}^{N} \lVert f_s^{(i)} - f_t^{(i)} \rVert_2^2$$
- 软标签蒸馏（教师输出作为软目标）
- 训练细节：`close_mosaic` 后半段关闭（避免小目标遮挡）

### 3.3 条件触发的伪装色增强
- 动机：田间害虫与稻叶同色系（绿色）对比度低
- HSV 绿色分析 → 绿色比例 $r_g$ → 当 $r_g > 0.1$ 触发
- 纹理增强（Laplacian）+ 色相偏移公式
$$H' = H + \alpha \cdot p \cdot M_{leaf} \cdot (H - 60^\circ)$$

### 3.4 多级开放集识别
- 类别自适应阈值 $\theta_k$（每类 0.40-0.75）
- 三级拒识：`low_confidence` / `uncertain_multiple` / `no_detection`
- 拒识后联动认知层兜底

### 3.5 语义知识库与 LLM 问答（认知层）
- FAISS 向量检索 + BM25 混合（hybrid）
- LLM 增强诊断 + 规则兜底（优雅降级）
- 知识库 332 条 / 80 个分块
