## 一、瓶颈诊断（来自 docs/_archive/REPORT.md 实测）

| 类别 | AP@0.5 | 问题类型 |
|------|--------|---------|
| small brown plant hopper（灰飞虱） | 14.6% | 小目标 + 类间混淆 |
| rice leaf roller（稻纵卷叶螟） | 23.5% | 小目标 + 伪装色 |
| brown plant hopper（褐飞虱） | 32.5% | 类间混淆 |
| white backed plant hopper（白背飞虱） | 36.0% | 类间混淆 |
| rice water weevil（水稻象甲） | 85.2% | 对照（大目标，AP 高） |
| mole cricket（蝼蛄） | 92.6% | 对照（大目标，AP 高） |

**核心结论（论文讨论章可写）**：
> 大目标类别（蝼蛄 92.6%、水稻象甲 85.2%）AP 高，说明模型本身没有问题；AP 低集中在小目标 + 飞虱三兄弟类间混淆。**问题源于"小目标特征信息量不足"与"类间可分性差"，而非模型容量不足**——这为"针对性优化"提供了方向依据。

**小目标的三重打击**：
1. 640×640 输入下，小目标（如灰飞虱若虫）可能只有十几个像素，经 YOLO 32×下采样后特征几乎丢失
2. 密集场景多个目标挤在一个网格单元，NMS 互相抑制
3. 飞虱三兄弟外观极相似（专家也需显微镜），类间距离极短

## 二、优化手段分级（已落地两个脚本）

### 级别 1：推理侧增强（立即可用，无需训练）✅ `scripts/multiscale_detect.py`

**原理**：图片放大后再推理，小目标像素更多、特征更清晰；多个尺度结果 NMS 融合。

| 模式 | 说明 | 适用 |
|------|------|------|
| `single` | 单尺度（与线上一致，基线对照） | 对照 |
| `multiscale` | 0.8/1.0/1.25/1.5 多尺度融合 | 离线高精度 |
| `sliding` | 大图切块放大推理 | 超大图/密集场景 |

**用法**：
```bash
python scripts/multiscale_detect.py --source 图片或目录 --mode all \
    --scales 0.8,1.0,1.25,1.5 --save output_dir
```

**论文定位**：
- 作为"推理侧增强"消融：验证多尺度对小目标 AP 的贡献
- ⚠️ 代价：多次推理延迟成倍增加（CPU 实时场景不划算），主要供**离线/论文实验**使用

### 级别 2：训练侧优化（推荐，部署无额外开销）✅ `train_small_object.py`

**三类手段，全部与论文基线同超参（保证公平）**：
1. **提高输入分辨率**：`imgsz=896/1024` —— 小目标像素更多（最直接有效）
2. **小目标数据增强**：mosaic + `copy_paste=0.3`（小目标复制粘贴）+ `scale=0.5`（多尺度模拟不同距离）
3. **可选 P2 小目标头**：`--model yolo11n-p2.yaml`（在 4× 下采样层加检测头，专门捕捉小目标；需 ultralytics 支持）

**用法**：
```bash
# 基线（公平对照）
python train_small_object.py --device 0 --imgsz 640 --name small_baseline_640
# 小目标优化（推荐）
python train_small_object.py --device 0 --imgsz 896 --name small_opt_896 --eval
# 更高分辨率
python train_small_object.py --device 0 --imgsz 1024 --name small_opt_1024 --eval
```

**论文定位**：
- 作为"增强实验"：证明**同样模型、同样部署开销下，提高分辨率+增强能显著提升小目标 AP**
- 是论文"讨论/未来工作"→ 可升级为正式实验的素材

### 级别 3：两阶段细粒度分类（未来工作，论文创新点）

对**飞虱三兄弟**（褐/白背/灰飞虱）做两阶段：
- 阶段一：检测器定位（飞虱类）
- 阶段二：裁剪飞虱区域 → 轻量细粒度分类器（如 EfficientNet-Lite）区分三兄弟

**论文价值**：这是"易混淆类"场景的**方法创新点**，可放进方法章或未来工作。工作量较大（需收集三兄弟细粒度标注），建议作为**后续工作**先在论文"未来工作"中提出，留出研究空间。

## 三、论文素材段落模板

### 3.1 实验章 · 小目标增强实验（中文草稿，配合消融）

> 针对小目标与易混淆类（灰飞虱 AP 仅 14.6%）性能偏低的问题，我们验证了两种针对性优化。**① 推理侧多尺度融合**：对输入图像以 0.8/1.0/1.25/1.5 倍尺度分别推理并 NMS 融合，小目标召回率显著提升，但推理延迟成倍增加，适用于离线高精度场景。**② 训练侧优化**：在保持模型与部署开销不变的前提下，将输入分辨率提升至 896，并引入小目标复制粘贴增强（copy-paste）与随机尺度增强。结果表明，训练侧优化在**不增加部署延迟**的情况下，将灰飞虱等小目标类别的 AP 提升了 X 个百分点，验证了"针对数据特性的轻量优化比扩大模型更具工程价值"。

### 3.2 讨论章 · 类间可分性分析（中文草稿）

> 飞虱三兄弟（褐飞虱/白背飞虱/灰飞虱）的 AP 显著低于大目标类别（蝼蛄 92.6%）。由于该类群个体形态高度相似、需显微观察区分，其性能瓶颈主要来自**类间可分性**而非模型容量。这一发现表明：对农业害虫这类"类内多样、类间相似"的目标，单纯增加模型参数收益有限，需结合细粒度分类等专门机制，这也是我们未来工作的方向。
